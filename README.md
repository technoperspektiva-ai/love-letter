# Love Letter 1.11.2 — Wizard Visual Polish

Повністю перепрацьовано візуальну композицію всіх mobile creator steps.

Основні зміни:
- заголовки більше не «висять у повітрі»;
- progress / title / count мають чітку ієрархію;
- magic visual тепер завжди сидить у власній surface;
- floating choice symbols перетворено на компактну композицію;
- кожен step має власну content card;
- inputs, labels, helper text, choices і final preview приведені до єдиної типографіки;
- short-screen layout теж окремо ущільнений;
- bottom actions не конфліктують із контентом.
