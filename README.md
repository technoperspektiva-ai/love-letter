Повний візуальний апдейт за обраним референсом.

- desktop dashboard: повноцінний hero, метрики, останні листи, ідеї, чернетка, декоративні paper/wax деталі;
- recent letter cards: тепер це інтерактивні «конверти» з hover-відкриванням, підйомом паперу, glow та CTA;
- desktop navigation: цілісна sidebar ecosystem з Home / Letters / Ideas / Settings / Create;
- library: новий hero, пошук, фільтри, letter-card grid;
- ideas: візуальні scenario cards, готові greetings, 36 activity ideas;
- mobile home: той самий дизайн-система, а не окремий випадковий responsive;
- mobile wizard: нова typography/color/button hierarchy;
- recipient: теплий ivory paper на burgundy experience, polished CTA;
- settings: приведено до тієї ж системи;
- усі ключові кнопки, cards, chips, focus/hover states уніфіковані;
- логіка short links, D1, edit/delete/copy, PWA, drafts та recipient flow не переписувалась.
