# Love Letter — story edition

Улучшенный статический MVP под Cloudflare Workers/Assets.

## Что внутри

- экран с секретным словом;
- персональное вступление;
- экран с конвертом и сургучной печатью;
- письмо на бумаге;
- опциональное фото внутри письма;
- экран выбора из 4 вариантов;
- финальная карточка приглашения;
- live preview прямо в конструкторе;
- всё работает без сервера и без базы данных.

## Как деплоить

Cloudflare deploy command:

```bash
npx wrangler deploy
```

Ничего дополнительно настраивать не нужно.

## Ограничение

Поскольку это полностью бесплатный статический MVP, данные хранятся прямо в hash-ссылке. Поэтому очень большие фотографии делают ссылку длинной. Для production-версии следующим шагом лучше вынести хранение в D1/R2.
