# Love Letter 1.12

## Портрет зі слів
- виправлено mobile upload: тепер він реально викликає word-portrait generator;
- портрет будується тільки з імені отримувача;
- новий алгоритм не стискає повне ім'я в крихітну клітинку;
- після завантаження фото одразу показується готовий preview;
- навіть старі portrait payload при показі використовують актуальне ім'я отримувача.

## Банк пропозицій
Додано 36 ідей у 6 категоріях:
- романтично;
- вдома;
- кудись вийти;
- спонтанно;
- майже без бюджету;
- на відстані.

Банк доступний прямо на кроці вибору та на сторінці Ideas.

## Recipient flow
- прибрані декоративні hearts/butterfly/sparkles з екрана вибору;
- choice cards зібрані в чистий список;
- фінал має одну ієрархію замість купи тексту й символів;
- біля `Поділитися вибором` є підсвічений блок:
  `Вибір уже враховано` + назва обраного варіанта.
